Local Ballistics
Calculator

A point-mass trajectory solver that runs on my own machine, built the week JBM Ballistics — the free calculator every handloader has a bookmark for — went dark.

Why it exists

JBM Ballistics was the internet's default drop calculator for twenty-some years: free, no login, no ads, just accurate exterior ballistics. When it got discontinued, the honest fix wasn't to hunt for a replacement website — it was to stop depending on a website at all.

So this is a real trajectory solver that lives on my computer, reads straight from my own handload database, and will keep working exactly like this whether or not any ballistics site is still online next year.

What it does

Solver
Point-mass (3DoF) integration via py_ballisticcalc — a Python port of JBM Ballistics' own published C code, extended per Bryan Litz's Applied Ballistics method.
Drag models
G1 and G7, selectable per bullet.
Table output
Range, time of flight, velocity, Mach, drop (in / MOA), windage (in / MOA), energy — one row per range step.
Comparison chart
Pin as many loads as you want onto one drop-vs-range plot, exactly like Figure 1 above.
Conditions
Altitude, station pressure, temperature, humidity, wind speed/direction, and uphill/downhill angle all feed the solve.
Spin drift
Optional — give it a twist rate and windage includes real spin drift, not just wind.
Data source
Reads bullet weight, chronographed velocity, and G1/G7 BC straight out of my 26-load handload database — pick a load by name instead of retyping numbers.
Runtime
Python + Tkinter, entirely local. No account, no network call, no data ever leaves the machine.

Why trust the numbers

Rather than hand-writing drag tables from memory — a real way to quietly get a hunting shot wrong — the solver is a library with its own CI test suite per integration engine. I checked it myself: fed it the library's own documented reference load (168gr, 0.223 G7, 2750 fps) and the output matched published values to the decimal, at every 100 m mark out to 1000 m. That check ships in the code, so it re-runs any time I want proof.
